💆 Simple Med Spa CRM

WhatsApp + Google Gemini AI + n8n (Self-Hosted) • Zero Third-Party Costs

How This Simple CRM Works

Patient sends a WhatsApp message or calls → n8n (running on your PC) receives it → Google Gemini AI responds with med spa context → Customer confirms booking → Data saved to local SQLite database → You see it in the CRM table.

ℹ️
Zero Cost Setup: n8n self-hosted (free), Google Gemini API (free tier: 60 requests/min), WhatsApp Business API (you set up once), SQLite local DB (free).

✓ What's Included

  • WhatsApp inbound messages & calls
  • Gemini AI responses (med spa context only)
  • Simple appointment booking flow
  • Client database (local SQLite)
  • Appointment history table

✗ What's NOT Included

  • Automated reminders (manual for now)
  • Payment processing
  • Complex analytics
  • Vapi voice calls (WhatsApp calls only)
  • Multi-language support

Installation & Setup (30 minutes)

  1. Install n8n on your PC

    Download from n8n.io or use Docker (recommended):

    docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n

    Then go to: http://localhost:5678

  2. Get WhatsApp Business API Setup

    Option A: Use WhatsApp Cloud API (free for testing, $0.005/msg after)

    Option B: Use WhatsApp Business App on your phone (simple, free, local)

    For this guide, we'll use WhatsApp Business API via n8n.

  3. Get Google Gemini API Key (FREE)
    • Go to: ai.google.dev
    • Click "Get API Key" → Create new API key (free tier = 60 req/min)
    • Copy the key and save it
  4. Create n8n Workflow (Simple Flow)

    New workflow with these nodes:

    1. WhatsApp Trigger (Listen for incoming messages) 2. Gemini Code Node (Send to Gemini API with prompt) 3. Parse Response 4. If "confirm booking" → Save to SQLite 5. Send response back to WhatsApp
  5. Set Up SQLite Database (Local)

    Install SQLite3 on your PC or use n8n's SQLite node.

    Create two simple tables:

    CREATE TABLE clients ( id INTEGER PRIMARY KEY, phone_number TEXT UNIQUE, client_name TEXT, email TEXT, created_at DATETIME ); CREATE TABLE appointments ( id INTEGER PRIMARY KEY, phone_number TEXT, treatment TEXT, appointment_date TEXT, status TEXT, created_at DATETIME );
  6. Add Gemini System Prompt to n8n

    This keeps AI focused on med spa only:

    You are a med spa receptionist AI assistant for Lumière Med Spa. TREATMENTS OFFERED: - Botox ($14/unit, 20–40 units typical) - Dermal Fillers ($650–950) - HydraFacial ($280) - Chemical Peel ($350) - Laser Resurfacing ($650) - Microneedling ($380) - Microneedling + PRP ($580) HOURS: Mon–Sat 9AM–7PM, Sun 10AM–5PM LOCATION: 45 Blossom Avenue, Suite 200 RULES: 1. Only discuss med spa services 2. If user asks non-med-spa questions, politely redirect 3. For bookings: ask name, phone, preferred treatment, preferred date/time 4. After confirming: ask "Are you sure you want to book this appointment?" 5. When user says YES → respond with "Booking confirmed! See you soon." 6. When user says NO → ask what else you can help with ALWAYS be professional, warm, and luxury-focused.
  7. Test the workflow

    Send a WhatsApp message to your business number. You should get an AI response from Gemini.

  8. Enable local n8n to run automatically on PC startup

    Use Windows Task Scheduler (Windows) or systemd (Linux) to start n8n when you turn on your PC.

n8n Workflow Code (Copy into n8n Editor)

{ "nodes": [ { "name": "WhatsApp Trigger", "type": "webhook", "parameters": { "path": "whatsapp-webhook", "method": "POST" } }, { "name": "Extract Message", "type": "set", "parameters": { "assignments": { "phone": "={{$json.body.From}}", "message": "={{$json.body.Body}}", "timestamp": "={{new Date().toISOString()}}" } } }, { "name": "Call Gemini API", "type": "httpRequest", "parameters": { "url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent?key={{YOUR_GEMINI_API_KEY}}", "method": "POST", "body": { "contents": [ { "parts": [ { "text": "{{$json.message}}" } ] } ], "systemInstruction": "You are a med spa receptionist... [USE THE PROMPT ABOVE]" } } }, { "name": "Parse Gemini Response", "type": "set", "parameters": { "assignments": { "aiResponse": "={{$json.candidates[0].content.parts[0].text}}" } } }, { "name": "Check if Booking Confirmed", "type": "if", "parameters": { "conditions": { "string": [ { "value1": "={{$json.message.toLowerCase()}}", "operation": "contains", "value2": "confirm" } ] } } }, { "name": "Save to SQLite (if confirmed)", "type": "sqlite", "parameters": { "operation": "executeQuery", "query": "INSERT INTO appointments (phone_number, treatment, appointment_date, status) VALUES ('{{$json.phone}}', 'User Treatment', '{{$json.timestamp}}', 'Booked')" } }, { "name": "Send Response Back to WhatsApp", "type": "httpRequest", "parameters": { "url": "https://api.twilio.com/2010-04-01/Accounts/{{TWILIO_SID}}/Messages.json", "method": "POST", "body": { "From": "whatsapp:+1234567890", "To": "whatsapp:{{$json.phone}}", "Body": "{{$json.aiResponse}}" } } } ] }
⚠️
Important: Replace {{YOUR_GEMINI_API_KEY}} with your actual API key. Never commit this to GitHub.

Appointment Booking Flow (Automated via WhatsApp)

This happens automatically when patient texts WhatsApp:

  1. Patient: "Hi, I want to book Botox"
  2. AI: "Great! I'd love to help. Which date works for you? We're open Mon–Sat, 9AM–7PM."
  3. Patient: "Next Tuesday at 10 AM"
  4. AI: "Perfect! That's Tuesday at 10 AM for Botox. Are you sure you want to book this appointment?"
  5. Patient: "Yes, confirm"
  6. AI: "Booking confirmed! See you Tuesday at 10 AM. We're located at 45 Blossom Avenue."
  7. n8n automatically saves: Phone, Treatment, Date, Status = "Booked"
